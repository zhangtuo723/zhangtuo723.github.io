保留已选定人物：自然、有个性的动画电影风成年男性，无眼镜、黑色露额上扫短发、深蓝夹克和米白 T 恤。此包用于接下来选择服务、生成网格与制作表情，不作为网页人物效果的完成证明。

## 使用顺序

1. 选择允许导出 GLB、支持所需使用与公开网页分发权限的图生 3D 服务；开始付费生成前核对当前套餐和输出权利。
2. 先上传 `front.png`，按需使用提示词；只有所选模式明确支持多视图时才分别追加侧面、背面等图片。不要把概念板上传给普通单图模式，也不要假设每项提示都是服务支持的独立参数。
3. 优先检查人物身份、脸型、眼睛、发型、颈肩与服装层级。严重偏离先重新选择结果，合格后保存原始 GLB/OBJ/FBX 与全部贴图。
4. 按制作规格修整面流、材质并制作面部表情。服务生成网格或提供全身自动绑定，不代表已包含可用的面部表情。
5. 在浏览器验证实际 GLB 的中性、微笑、独立眨眼和转头，再接入主页；最终静态封面取自同一实际模型。

这些视图是分次生成的设计参考，局部细节可能不一致；正面图为造型基准。当前输入到大腿中段，首先用于网页头肩胸像；若要完整腿脚和全身动作，需先补足全身参考。

已知侧面图胸袋左右对应不可靠，制作时按正面保留人物自身左胸的单个橙标胸袋。侧面图用于人工检查轮廓；需要严格一致的多视图输入时，应先修正左右对应。

目前没有配置任何相关服务账号、API Key 或自动上传步骤。不要把密钥写入仓库、提示词或浏览器端代码。
