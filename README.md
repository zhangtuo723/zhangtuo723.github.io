# zhangtuo · Agent 科技工厂

面向公开展示的个人简介与作品集。主场景是一座由 Three.js 几何构成的 Agent 科技工厂：服务器机架、动态显示器、办公工位、传送装置和机器人分布在不同区域，中央调度台与通道连接四个项目区。滚动页面时，镜头从工厂总览飞越各区，将个人介绍与项目逐一展开。

视觉采用深蓝金属空间、银灰设备、冰蓝与青色屏幕，以及少量橙色警示标识。场景中的设备、屏幕数据、服务机器人和工业机械臂均为本地视觉演示，没有接入存储后端、真实设备控制或 AI 服务。

网站：https://zhangtuo723.github.io

## 本地开发

无需安装 Node 依赖或执行构建，在仓库根目录启动静态 HTTP 服务：

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

浏览器访问 `http://127.0.0.1:8080`。Three.js 使用原生 ES 模块，需要 HTTP 服务，不能直接双击 HTML 文件。

## 体验与技术

- **滚动参观**：七个章节依次介绍工厂、本人、ForgeKit、内容分析助手、FlappyBird 强化学习、Qwen3 唐诗生成和联系方式。滚动位置控制镜头，导航按钮可以直接跳转，主体验无需使用方向键操控行走。
- **四个项目区**：工具生产区对应 ForgeKit，数据分析区对应内容分析助手，机器人实验区对应强化学习，模型创作区对应唐诗生成。服务器、显示屏、办公设备和机械装置组成可探索的工厂空间。
- **项目装置**：工具模块、报告终端、学习实验装置和电子诗集承载四个真实项目的介绍。点击相关三维装置可快速跳转到对应章节，HTML 按钮提供同样的入口。
- **机械动画**：轮式服务机器人沿预设路线巡游，工业机械臂和传送装置执行预设动画。实验区另放置一个采用 CC0 许可的成品机器人，使用原有骨骼与待机、招手动画。没有接入真实机器人控制、智能寻路、Agent 决策或在线训练；关闭动态效果时停止动画。
- **流程演示**：中央终端的约五秒本地动画展示任务、工具编排、内容分析与报告的关系；不发起真实 AI 请求，不代表网站正在运行 Agent 或训练模型。
- **项目详情**：原生 `dialog` 展示项目说明和链接，支持键盘、ESC 关闭及关闭后的焦点恢复。
- **静态阅读**：普通阅读模式、关闭动态效果、系统减少动态效果偏好及 WebGL 不可用时均保留正文和项目链接。首次以普通版或低动态设置访问时，不下载或启动 Three.js 场景。普通版可通过 `?view=plain` 直接访问。
- **本地资源**：Three.js、字体和图像随仓库提供，本站内容展示不依赖外部 CDN。
- **发布**：纯 HTML、CSS 和原生 JavaScript，使用 GitHub Pages 根目录静态部署；没有后端、API key 或三维人物生成服务依赖。

阅读和动态偏好保存在浏览器本地。本站没有统计脚本；访问项目或 GitHub 链接会离开本站。

修改项目时同步 `index.html` 的章节内容与 `site.js` 的 `workData`。个人信息和项目介绍沿用原仓库内容，没有虚构教育、任职年月或成果指标。

工厂封面和分享封面从当前完整场景渲染获取，便于低动态模式保留相同的设计；修改空间布局、设备或配色后应重新导出，不能沿用此前桌面模型或暖色工作室的截图。`assets/modular-tools.webp` 与 `assets/neural-sculpture.webp` 是项目详情使用的概念图，不是产品截图。

`design/character-generation/` 保留此前的人物设计探索与生成输入资料，属于历史设计记录，不是当前网站的交付流程；维护或运行本站无需注册三维生成服务。

## 验证

基础语法检查：

```bash
node --check site.js
node --check scene.js
node --check workshop.js
node --check factory-props.js
node --check factory-robot.js
```

启动静态服务后，使用支持 WebGL 的浏览器检查：七个章节的滚动运镜、各项目区的构图与文字可读性、装置与导航跳转、机器人和机械动画及关闭动态效果后的停止、四个项目详情、ESC 与焦点恢复、手机布局、邮箱复制、本地流程演示、普通模式、系统低动态偏好及 WebGL 不可用时的展示。检查控制台和网络请求，确认没有缺失资源，并确认普通版或低动态首次访问未加载三维模块。静态封面应与当前工厂布局和配色一致。

云端 Playwright 使用软件渲染时可能停帧，预览检查可为测试 Chromium 添加 `--disable-frame-rate-limit`；这只是测试环境选项，网站访客无需配置浏览器。云端手机尺寸模拟不能代替真实手机的操作和性能验证，不以软件渲染的帧率推断用户设备表现。

## 设计与素材

科技工厂、项目区、轮式服务机器人、工业机械臂、场景布局和滚动镜头为本项目独立实现。场景以程序几何和画布纹理为主，重复设备使用实例化或合并网格组织。实验区的 RobotExpressive 成品来自 Quaternius / Tomás Laulhé，由 Three.js 官方分发，采用 CC0 1.0 许可；本站调整主壳配色与展示比例，保留骨骼、表情和动画，不依赖角色生成服务。屏幕上的仪表和数据是场景演示内容，不是实际存储系统或在线训练的监控结果。

后续可优先从 [Quaternius](https://quaternius.com/)、[Kenney](https://kenney.nl/assets) 查找风格化道具，从 [Poly Haven](https://polyhaven.com/) 查找环境与材质。逐项确认具体模型的许可、纹理来源和体积，下载并随仓库保存，避免运行时依赖外部素材链接。免费价格不能代替使用许可；本次只有上述机器人经过核验并实际纳入。

此前研究过 [dayinji/sen-3d-resume](https://github.com/dayinji/sen-3d-resume) 的滚动叙事方式，未使用其人物模型或个人资料。用户另提供 `jds110.xyz` 作为参考；本次环境未能访问核实其页面，因此不将它列为已复现的设计来源。
